# 视频文字检查工具

这是第一版可运行工具。它在当前电脑上打开网页，不需要云服务器。

## 启动

在此文件夹运行：

```bash
python3 -m uvicorn app:app --host 127.0.0.1 --port 8000
```

然后打开：<http://127.0.0.1:8000/>

## 第一版已经支持

- 一次上传多个 SRT 字幕。
- 上传 Word 文稿和 Excel 审核词表。
- 检查字幕在文件中是否放错位置。
- 检查相邻字幕时间是否重叠。
- 查找审核词表中的词，并显示完整句子和时间段。
- 审核人员填写“确实有问题、系统提示错了、已经处理好、我不确定”。
- 下载问题清单 Excel。
- 汇总人工复核结果，下载“待整理建议”Excel。
- 清除本次检查数据。
